# Лабораторная работа 2: Классы и инкапсуляция

Условие: [«Классы и инкапсуляция»](../assignments/lab02-domain-model.md).

## Вариант
Инженерия систем искусственного интеллекта.

## Подготовительная часть
Реализован `BankAccount`: баланс закрыт; начальный баланс неотрицателен; пополнение и списание принимают только положительные суммы; превышение остатка и переполнение запрещены. Баланс доступен через `getBalance()`, setter отсутствует.

## Обязательная часть
Реализованы `DataSample` и перечисление `SampleStatus`.

### Инварианты DataSample
1. `id` и `label` не равны `null` и не состоят только из пробелов.
2. `status` не равен `null`.
3. `features` не равен `null` и содержит хотя бы один элемент.
4. Все значения признаков являются конечными числами.
5. Массив копируется при создании объекта и при вызове `getFeatures()`.

### Поведение
- `changeStatus` меняет статус и запрещает `null`.
- `isReady` проверяет статус `READY`.
- `getAverageFeatureValue` вычисляет среднее арифметическое признаков.
